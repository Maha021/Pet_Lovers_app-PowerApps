Furora🐾

Furora is a simple and user-friendly pet adoption app built using Microsoft Power Apps.
I created this project to learn Power Apps practically by designing a real-world scenario around pet care and adoption.

The app helps users browse pets, check their adoption status, and easily find the right companion — all with a clean and soft UI experience.
What this app can do,
1) Search pets by name or pet type
2) Filter pets based on adoption status (Available, Adopted, Not for Adoption)
3) Visual color indicators to quickly understand availability
4) Data connected and managed using SharePoint
5) Simple, responsive design with a light purple theme

Built With,
1. Microsoft Power Apps (Canvas App)
2. SharePoint Online (as the data source)
3. Power Fx for app logic and formulas

Purpose of this Project:

This is a learning and portfolio project created to:
1) Practice Power Apps from scratch
2) Understand real-time data handling with SharePoint
3) Improve UI design and user experience
4) Showcase no-code/low-code application skills

"Furora" reflects my journey of learning Power Apps by building something meaningful and practical.
